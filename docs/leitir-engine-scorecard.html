Next enhancement

Pick

Fix the trafilatura env-parity hole (Step 3 extraction)

Lowest-scoring functional bolt (3/10) and the consensus "#2 build-first" item from all three reviewers. It is the single biggest reason real grounding doesn't happen: even when discovery works, extraction silently zeroes every fetched doc on a missing import. Cheap, high-leverage, unblocks Tier-1/2 grounding for everything downstream.

Concrete: a leitir doctor production-image readiness check that imports trafilatura and extracts one fixture before any run; make cleaned_tokens==0 a loud infrastructure_invalid, not a silent degrade; run ≥1 eval task in the published image, not the dev venv.

But first — the immediate blocker to land the grounding gate

GPT-5.6-sol found the gate only protects the orchestrator's internal loop. The exported Step5Controller.verify() still ACCEPTs on a PASS without the grounding check — so a caller on the public API bypasses the gate. Centralize the invariant (or remove that method from the acceptance surface), then the gate goes 4 → ~7 and lands. See the split verdict below.
