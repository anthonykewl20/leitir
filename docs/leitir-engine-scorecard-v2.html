Verdict

What the rebuild fixed

Mean health 3.7 → 7.0; the four v1 integrity failures are structurally gone

The v1 scorecard's four worst bolts — false-green acceptance (1.0), hallucination-prone synthesis (4.5), zero reproducibility, and model spend — cannot exist here by construction: there is no model, no acceptance gate to fool, reports are byte-reproducible (verified today), and cost is zero. Seven of fourteen bolts now score good (8–10); the contracts and the honest-coverage invariant are near-flawless because the type system, not a reviewer, enforces them.

Two evidence-backed priorities

1. Finish ADR-001: delete the old engine. 2. Build P6: prove the search is actually good.

#1 (3.0): the premise "we threw it all out" is false at the code level — __init__.py still exports the Hy3 pipeline, 60% of tests still exercise it, pyproject.toml still depends on Docker/trafilatura, and the README still describes it. Delete the dead modules, prune the three deps, rewrite the README, and the bolt moves to good.

#2 (2.5): 486 green tests prove the engine runs; nothing proves it finds the right code. Ship P6 (ranking.py + leitir bench + ≥10 pinned tasks with expected results) so effectiveness is a gate, not a hope.
